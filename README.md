<h1 align="center">Trump Switcher</h1>
<p align="center">Локальное исправление русской и английской раскладки для macOS</p>
<p align="center"><a href="README.en.md">English</a> · <a href="https://github.com/Nazhmetdinov/trump-switcher/releases/latest">Скачать установщик</a> · <a href="CHANGELOG.md">История изменений</a> · <a href="THIRD_PARTY.md">Лицензии словарей</a></p>

Trump Switcher исправляет слово, случайно набранное в другой раскладке. Наберите `ghbdtn` и пробел — получите «привет»; `руддщ` превратится в `hello`. Приложение работает в строке меню и не требует учётной записи.

## Почему Trump Switcher

- **Только на вашем Mac.** Словари входят в приложение. При запуске оно включает системный запрет сетевых подключений; история набора не сохраняется.
- **Обе стороны переключения.** Русский ↔ английский, короткие слова, смешанные буквы, знаки препинания и адреса. Неоднозначное слово остаётся как набрано.
- **Гибкие правила.** Свои замены, исключения для слов и приложений, ручное исправление и пауза — через понятные настройки.
- **Контроль в ваших руках.** Автозапуск по выбору, без аккаунта, телеметрии, облачных словарей и автоматических загрузок.
- **Открытый исходный код.** Реализация и состав словарей доступны для проверки.

Автозамена срабатывает после пробела, а при включённой настройке также после Enter и Tab. Однозначные знаки препинания могут завершать слово сразу. Например: `lkz` → «для», `b` → «и», `ghbdtn!` → «привет!».

## Установка

1. Скачайте [последний DMG](https://github.com/Nazhmetdinov/trump-switcher/releases/latest) для **Apple Silicon (M1 и новее)** и **macOS 13+**.
2. Откройте образ и перетащите **Trump Switcher** в папку **«Программы»**.
3. Запустите приложение из «Программ» и предоставьте доступ **«Универсальный доступ»** (Accessibility), когда macOS попросит. Он нужен для чтения текущего слова и отправки исправленного текста.
4. Откройте настройки через значок в строке меню. Там можно включить запуск вместе с Mac.

Сборка подписана локально и пока **не нотариализована Apple**. При первом запуске macOS может показать предупреждение о непроверенном разработчике. Используйте стандартное системное действие **«Открыть»** для приложения, которому доверяете; установщик не меняет настройки безопасности автоматически.

## Безопасность и ограничения

При старте приложение применяет локальный профиль macOS `kSBXProfileNoInternet` и проверяет запрет сетевых сокетов. Если защита недоступна, запуск прекращается. Набираемые слова кратковременно находятся в памяти для исправления; журнал ввода и отправка текста не предусмотрены. Поля паролей и защищённый ввод исключаются. Подробнее: [политика безопасности](SECURITY.md).

Работа зависит от возможностей конкретного текстового поля и разрешения Accessibility. Составной ввод IME, защищённые поля и приложения, блокирующие синтезированные нажатия, могут не поддерживаться. Абсолютную совместимость со всеми программами проект не обещает; неоднозначные случаи намеренно сохраняются без замены.

Проект **не связан** с Дональдом Трампом, его организациями, Яндексом или Punto Switcher. Никакой код или закрытый словарь Punto Switcher не включён.

## Исходники и сборка

Код написан на Swift, C и C++. В текущем сценарии сборки требуется macOS SDK **26.5** и Swift **6.4**. Исходники Hunspell и локальные словари включены; сетевые загрузки во время сборки не нужны.

```bash
bash scripts/build.sh
```

Для подготовки DMG нужны только локальные инструменты из `scripts/installer-requirements.txt`:

```bash
DMGBUILD_PYTHON=/path/to/packaging/python bash scripts/package-release.sh
```

Готовое приложение появляется в `Build/`, образ и ZIP — в `Releases/`. Проверки сборки запускаются через `scripts/build.sh`; их объём и ограничения описаны в [VALIDATION.md](VALIDATION.md).
