# Security / Безопасность

Trump Switcher has system-wide Accessibility access while running. Treat it as a
privileged local utility. The current-token buffer is kept in memory only; no
telemetry, account, updater or network-dependent dictionary is included. The
app applies and verifies macOS's no-internet sandbox at startup.

Please report a security problem privately through GitHub's private vulnerability
reporting if available for this repository. Otherwise contact the maintainer via
his GitHub profile before publishing exploit details. Include the app version and
minimal synthetic steps. Do **not** attach real typed content, passwords,
screenshots of private conversations or system permission dumps.

Приложение получает системный доступ «Универсальный доступ», поэтому относится
к локальным утилитам с повышенными разрешениями. О проблемах безопасности
сообщайте приватно через GitHub, если доступна функция private vulnerability
reporting, либо свяжитесь с владельцем через его профиль. Используйте только
вымышленные примеры; не прикладывайте реальную переписку и пароли.

Supported releases: the most recent published release. No guarantee is made
for unsupported macOS versions, IMEs or fields that block generated events.
